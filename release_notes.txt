================================================================================
  SSL Center WHMCS Addon (SSLCENTERWHMCS) - Release Notes
  GoGetSSL reseller integration for WHMCS
================================================================================

  Repository : https://github.com/gogetssl/whmcs-addon
  Releases   : https://github.com/gogetssl/whmcs-addon/releases
  Wiki       : https://github.com/gogetssl/whmcs-addon/wiki

  Entries are listed newest first. Each entry shows the version, the release
  date (YYYY-MM-DD) and the changes, grouped as:

    [!]      Action required after upgrading
    Added    New features
    Changed  Changes to existing behaviour
    Fixed    Bug fixes
    Removed  Removed features or options

  Issue numbers (#123) refer to https://github.com/gogetssl/whmcs-addon/issues

  General upgrade steps
    1. Back up your WHMCS files and database.
    2. Upload/replace modules/addons/SSLCENTERWHMCS and
       modules/servers/SSLCENTERWHMCS.
    3. Open System Settings > Addon Modules (WHMCS 7: Setup > Addon Modules)
       so the addon's database upgrade runs. Disable and re-enable the addon
       when an entry below says so.
    4. Check that all cron jobs listed on the addon's API Configuration page
       are set up.

v3.1.9 (2026-10-09)
-------------------
Changed
  - AutoInstall SSL (+ Automate) products are now recognised by their
    GoGetSSL API product ID (400 RapidSSL Plan, 401 RapidSSL Wildcard Plan,
    402 GeoTrust DV Plan, 403 GeoTrust DV Wildcard Plan) instead of the
    product name. Detection no longer depends on the cached product list, so
    AIS services always open the AutoInstall SSL page even if the product
    cache is empty or outdated. Existing AIS services are not affected.
Added
  - release_notes.txt with the full version history, included in every
    release package.

v3.1.8 (2026-09-10)
-------------------
Fixed
  - TypeError "implode(): Argument #2 ($array) must be of type ?array, string
    given" on the client-area certificate details page when showing HTTP/HTTPS
    validation file content. Lines are now printed and escaped one by one.

v3.1.7 (2026-09-08)
-------------------
Changed
  - Deactivating the addon no longer deletes its database tables and email
    templates, so settings and order data survive a disable/re-enable.
Fixed
  - Certificate details page is now fully translatable: status banners,
    badges, downloads, tabs, order info, buttons and renewal messages use
    language strings (about 100 new English keys).
  - "Change Validation Method" now includes the main domain, not only SANs,
    and saves the methods that were actually submitted.
  - Switching to Email validation sends the selected approver email address
    to the API.
  - Private key is shown and included in the PEM download whether it is
    stored plain or encrypted; it is HTML-escaped in the private key dialog.

v3.1.0 (2026-07-23)
-------------------
[!] Add two new cron jobs (commands shown on the API Configuration page):
    the cron queue processor (every 5 minutes) and the active orders check
    (every 12 hours). Ten new email templates are installed on upgrade.
Added
  - New client-area SSL Configuration page replacing the WHMCS configure-SSL
    steps:
      * install type: AutoInstall via cPanel or Manual Enrollment
      * domain picker from the client's cPanel accounts (optionally with www)
      * automatic CSR generation or own CSR
      * validation method Email / HTTP / HTTPS / DNS, with optional fallback
        email for DNS
      * admin and tech contacts, single and wildcard SANs, new/renew order type
  - Redesigned certificate details page: status banner and badges, PEM / CRT /
    private key / CA bundle downloads, Install on Server, Resend Validation
    Email, Renew Now, per-domain validation instructions, Certificate Activity
    timeline and a Change Validation Method dialog.
  - AutoInstall automation via a cron queue: polls domain validation, uploads
    HTTP/HTTPS validation files to cPanel, installs the issued certificate on
    cPanel and reissues automatically before expiry. DNS validation that keeps
    failing is switched to email (wildcards after a configurable timeout).
  - Active orders check: detects expired certificates (one-time notice) and
    syncs next due / next invoice dates with the certificate end date.
  - Settings "Wildcard DNS Validation Timeout (minutes)" (default 65) and
    "Auto-Reissue Days Before Expiry" (default 7).
  - Email templates: renewal invoice, renewal started, renewal complete,
    auto-renewed, certificate revoked, DNS-to-email switch, auto-reissue
    failed, certificate installed, certificate expired, validation warning.
